### 🚀 Featured Projects

**AegisRAG** — Citizen-query-style RAG evaluator & MCP knowledge agent  
`LangChain` `LangGraph` `MCP` `ChromaDB` `Ragas` `Guardrails`
* Benchmarked 4 retrieval strategies across a 50-query dataset — Context Precision@5: 51% → 83%, Answer Faithfulness: 96%
* Guardrails for hallucination detection, off-topic blocking, and PII redaction

**CodeSentinel** — Autonomous multi-agent code review & triage system  
`Python` `LangGraph` `FastAPI` `Redis` `ChromaDB`
* 4 parallel LLM agents (Security, Style, Logic, Test Coverage) via a LangGraph StateGraph
* Async FastAPI + Redis + RQ pipeline acknowledging webhooks in <1ms; HMAC-SHA256 verification; validated by a 60-test Pytest suite

**Traffic-Congestion-Detector** — Fine-tuned YOLOv8 vehicle detector & PCU congestion classifier  
`Python` `PyTorch` `YOLOv8` `Roboflow` `OpenCV`
* Custom 696-image dataset, 5 vehicle classes — mAP@0.50: 0.823, Recall: 0.843
* Custom Passenger-Car-Unit scoring algorithm for real-time congestion labeling
